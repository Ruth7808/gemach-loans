הקשר: זה פרויקט קיים (מערכת ניהול גמ"ח כספים, React+TS / Node+Express+TS /

במסך יצירת הלוואה — אלה בשלב ב׳, בכוונה, כדי לא לקחת יותר מדי בבת אחת.**

## 1. סכימת Prisma — צור את כל 4 הטבלאות עכשיו (גם אם 2 מהן לא ישמשו עדיין)

צור מיגרציה אחת שמוסיפה:

**Depositor** (מקביל ל-Borrower הקיים — השתמש באותה קונבנציית שמות שדות):
שם פרטי, שם משפחה, טלפון, מייל (אופציונלי), כתובת (אופציונלי), הערות,
תאריך יצירה.

**Deposit** (מקביל ל-Payment, בלי Allocation — הפקדה היא כסף שנכנס בלי לוח
תשלומים מתוכנן): מזהה מפקיד (קשר ל-Depositor), סכום, תאריך, הערות,
תאריך יצירה.

**WithdrawalRequest** (**רק סכימה בשלב הזה, לא נבנה API/UI עדיין**): מזהה
מפקיד, סכום מבוקש, תאריך בקשה, תאריך יעד, סטטוס
(`פתוחה`/`שולמה_חלקית`/`שולמה`/`בוטלה`), סכום ששולם עד כה (ברירת מחדל 0),
הערות, תאריך יצירה, תאריך עדכון.

**Withdrawal** (**רק סכימה בשלב הזה**): מזהה בקשת משיכה (**חובה nullable**),
מזהה מפקיד, סכום, תאריך, הערות, תאריך יצירה.

**הוסף ל-Setting**: מפתח `withdrawal_notice_days`, ברירת מחדל 30.

## 2. עדכון נוסחת "כסף פנוי" — נקודה קריטית

מצא את הפונקציה/שירות הקיים שמחשב כסף פנוי (כרגע: יתרת פתיחה + Σתשלומים −
Σהלוואות) ועדכן אותה **במקום, לא כפונקציה מקבילה חדשה**, לנוסחה:

```
כסף פנוי = יתרת פתיחה + Σתשלומים + Σהפקדות − Σהלוואות − Σמשיכות
```

מכיוון ש-Withdrawal ריק בשלב הזה, השינוי היחיד בפועל הוא הוספת Σהפקדות.
**בדוק שהדשבורד עדיין מציג מספרים נכונים אחרי השינוי** (עם 0 הפקדות קיימות,
המספר לא אמור להשתנות כלל).

## 3. API — CRUD למפקידים והפקדות בלבד

`/api/depositors`:
- GET (רשימה + חיפוש), GET/:id (פרטים + הפקדות + יתרה נטו = Σהפקדות שלו),
  POST, PUT, DELETE (חסום אם יש הפקדות קיימות)

`/api/deposits`:
- GET (עם סינון `?depositorId=`), POST, PUT/:id, DELETE/:id

**אל תבנה עדיין** `/api/withdrawal-requests` או `/api/withdrawals`.

## 4. מסכי צד לקוח

1. **ניווט** — הוסף פריט "מפקידים" ל-sidebar, עם צבע/אייקון זהות משלו
   (עקבי עם עקרון הזהות הויזואלית שכבר קיים במערכת — כל אזור ניווט צבע
   משלו).

2. **רשימת מפקידים** — מקביל למבנה רשימת הלווים: טבלה, חיפוש, כפתור הוספה.
   עמודות: שם, יתרה נטו (סה"כ הפקדות).

3. **כרטיס מפקיד** — פריסת פרופיל (לא טבלה) כמו כרטיס לווה: שם + פרטי קשר
   + יתרה נטו למעלה, רשימת הפקדות מתחת, כפתור "רשום הפקדה". **אל תוסיף
   עדיין** אזור בקשות משיכה בכרטיס — זה בא בשלב ב׳.

## 5. בדיקות לפני שממשיכים לשלב ב׳

- ודא שכסף פנוי בדשבורד עולה כשמוסיפים הפקדה.
- ודא RTL תקין בכל המסכים החדשים ושהם לא שוברים ניווט קיים.
